## 핵심 변화 3가지

1. **공개 가입 모델로 전환**
   - 기존(V1): 운영자가 친구를 한 명씩 등록하고 1:1 토큰 링크 발송
   - 변경: 누구나 가입 페이지에서 본인 정보를 직접 등록 (일반 소개팅 사이트 결)

2. **운영자 역할 축소**
   - 기존: 운영자 = 친구 CRM 관리자 + 매칭 결정자
   - 변경: 운영자 = **매칭 검토자 only** (등록 관리는 사용자 자신이)

3. **안전 장치 = 추천인 필수**
   - 가입 시 "운영자가 아는 사람" 이름 입력 필수
   - "친구의 친구"까지만 망 확장 허용
