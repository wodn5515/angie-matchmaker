# 000 — Initial Decisions (Interview Outcome)

> 인터뷰를 통해 결정된 사항들을 시간순/주제순으로 정리한 문서. 이후 결정은 별도 번호 파일로 추가됨.

## 0. Project Identity
- **Repo**: matchmaker
- **Concept**: 운영자(개인)가 자기 지인들을 데이터베이스화하고 1:1로 잘 어울릴 사람끼리 중매하는 개인 CRM
- **For**: chrisjohn(개발자) — 본인의 지인(=비개발자 운영자)에게 만들어 주는 토이 프로젝트

## 1. User Model
- **운영자 = 1명** (chrisjohn의 지인). 멀티 운영자 SaaS는 V1 대상 외, 데이터 모델만 미래 대비
- **친구(Subject) = 계정 없음.** 운영자가 친구 카드를 직접 만들고, 1회용 토큰 링크로만 본인 설문에 접근
- **운영자 ≠ 개발자** → 모든 설정/편집은 UI에서 가능해야 함. 코드/환경변수 수정은 chrisjohn만 가능

## 2. Tokens (Survey Invitation)
- 토큰 = (Friend × Survey) 단위 1회용
- 응답 완료 전이면 같은 링크로 재진입해서 이어풀기 가능
- 응답 완료되면 토큰 만료, 같은 링크 재진입 시 만료 화면

## 3. Survey Structure
- **표준 설문 1개 + 챕터식 진행** (게이미피케이션 친화)
- **커스텀 설문**: 운영자가 친구별로 따로 보낼 수 있음. 응답은 운영자만 봄, 자동으로 프로필에 합쳐지지 않음. 필요 시 운영자가 수동으로 메모/태그에 옮김
- **운영자 직접 입력 메모**도 별도 존재
- **문항 타입**:
  - 표준/공통: 객관식, 우선순위(랭킹), Likert 척도
  - 커스텀에서만 추가: 주관식 (자유 텍스트)

## 4. Friend Profile (티어링)
- **Tier 1 (등록 시 필수)**: 이름, 성별, 선호 성별
- **Tier 2 (등록 시 권장, 건너뛰기 가능)**: 나이/생년, 거주 지역, 직업, 친밀도, 어떻게 알게 됐는지, 태그
- **Tier 3 (나중에 운영자가 추가)**: 인스타, 카톡 ID, 전화, 자유 메모, 매칭 이력
- **Tier 4 (원래 친구 자가입력 영역이지만 → 운영자 수동 입력으로 단일화)**: 연애 상태, 매칭 관심도
  - 결정 근거: 친구가 답해도 운영자가 수정할 거라 하나로 통일하는 게 모델 단순
- **사진**: 사용 안 함

## 5. Survey Delivery & Notifications
- 발송 = 운영자가 토큰 링크를 카톡으로 직접 복붙
- 앱 자동 발송(이메일/SMS) 없음
- 응답 도착 알림 없음. 운영자가 대시보드에서 직접 확인

## 6. Matching
- **방식 = B (수동, 비교 뷰 only)**. LLM/점수 기반 추천 없음 (토이 스코프 + 비용 회피)
- 비교 뷰: 1:1 only
- 비교 뷰 진입: 친구 리스트에서 한 명 선택 후 다른 한 명 추가, 또는 친구 상세에서 비교
- 자동 하이라이트(같은 답=초록 / 다른 답=빨강)는 점수 없이도 시각적 단서로 제공
- **Pair 엔티티**로 비교 메모와 매칭 이력을 통합 (별도 테이블 아님)

## 7. UI/UX
- **모바일 웹** (네이티브 앱 X), 반응형
- **운영자 화면** = 미니멀 모던 + 다크 (Linear 다크모드 톤)
- **친구 화면** = 챕터 클리어형 + 심리테스트 톤 혼합 (게이미피케이션)
- **브랜드 컬러** = Black base + Pink accent
- 친구는 답변 완료 후 "수고했어" 정도의 가벼운 완료 화면. 점수/결과 공유 없음
- **개인화 인사**: "안녕, [이름]! [운영자명]이 보낸 설문이야 🎀"

## 8. Auto-Save (친구 응답)
- **하이브리드**:
  - 객관식 / Likert / 우선순위 → 선택 즉시 저장
  - 주관식 텍스트 → debounce 1.5초 저장
- 화면에 작은 "저장됨 ✓" 표시
- 토큰=신원이라 폰→PC 등 디바이스 간 이어풀기 자동 지원

## 9. Auth
- **Google OAuth + 단일 이메일 화이트리스트** (Supabase Auth)
- 환경변수 `OPERATOR_EMAIL` 과 일치할 때만 운영자 권한
- 다른 Gmail 로그인 시 차단/로그아웃

## 10. Tech Stack
- Next.js 15 (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (Postgres + Auth)
- Vercel (배포)
- Docker 사용 안 함 (Vercel 직접 배포가 더 자연스럽고 무료)
- 비용 = $0/년 (vercel.app 서브도메인 사용)

## 11. Out of Scope (V1)
- 자동 매칭 점수/추천, LLM 분석
- 다중 운영자
- CSV 내보내기 / 데이터 백업
- 알림 인프라 (이메일/SMS/푸시)
- 다국어 (한국어 only)
- 친구 본인 계정 / 결과 공유

## 12. Initial Surveys
- 표준 설문은 빈 상태로 배포 → 운영자가 UI에서 챕터/문항을 직접 만듦
- chrisjohn이 시드 문항을 채워두진 않음
